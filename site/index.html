Case and trailing spaces in string comparison

casemysqlmariadbpostgresmssql
'a' = 'A'equalequaldifferentequal
'a' = 'a ' (trailing space)differentequaldifferentequal
'a' = ' a' (leading space)differentdifferentdifferentdifferent

PostgreSQL is case-sensitive for 'a'='A'; the others (default collations of these images) are not. Trailing space: MySQL 8.4 differs, MariaDB and SQL Server ignore it. MySQL docs: PAD SPACE collations ignore trailing spaces, NO PAD ones do not; Unicode UCA 9.0.0+ collations are NO PAD, which matches the MySQL 8.4 result. Why MariaDB and SQL Server behave so: not checked.
